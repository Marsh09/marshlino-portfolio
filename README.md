# Marshlino's Engineering Hub

Personal portfolio website for **Marshlino Nader**, a second-year Computer Engineering student at Pharos University, Alexandria, Egypt. Built for internship applications and personal branding.

**Live site**: https://marshlino.lovable.app

## About

Second-year Computer Engineering student at Pharos University in Alexandria, Egypt. Coursework covers digital systems, electronics, data structures, linear algebra, and probability. This portfolio showcases embedded systems, circuit design, and software projects.

## Projects

- **SOS Safety Device** — Arduino-based emergency device integrating a SIM800L GSM module, Neo-6M GPS module, ultrasonic sensor, and buzzer for automated distress alerts.
- **Interactive Parking Counter Circuit** — Digital systems project using JK flip-flops (74LS76), IR sensors (TCRT5000), a BCD decoder (74LS47), and 7-segment displays.
- **Infix-to-Postfix Converter** — C programming project applying stack-based data structures.
- **Supermarket Sales Data Analysis** — Python/Pandas project covering data cleaning, profiling, and business-question analysis on a retail dataset.
- **Also exploring** — Bluetooth-Controlled Smart Agricultural Rover, Fire Detection & Alert System, Smart Blind Stick.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone https://github.com/Marsh09/marshlino-portfolio.git
cd marshlino-portfolio
npm i
npm run dev
```

The dev server runs at http://localhost:8080.
